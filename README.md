# Rakesh Gangani — eCommerce Portfolio

Static portfolio site for Shopify, Magento and BigCommerce services.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html`.
2. Replace the LinkedIn placeholder with your profile URL.
3. Add your profile photo if desired.
4. Add verified client/project names only where you have permission to disclose them.
5. Deploy to your preferred static hosting and connect your domain.
